# Remora

A native Android remote-control client for Raspberry Pi/Linux, built with **Rust** and **Slint**.

Remora is intended to provide a touchpad, keyboard, clipboard, application launcher and Moonlight-friendly controls while keeping the existing Raspberry Pi/Wayland control service.

## Project status

Early development. The Android UI prototype lives on the [`dev` branch](../../tree/dev). The existing Pi service and web client remain unchanged.

- **`main`** — stable code and eventual signed releases.
- **`dev`** — Android development and downloadable test APKs in GitHub Actions.

See the dev branch for source code and build instructions. The first test APK is a UI prototype, not a connected remote controller.
